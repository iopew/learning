# ActivityTracker

Личный трекер активности для macOS. Живёт в строке меню, каждые 5 секунд записывает, чем ты занят, и показывает статистику. Все данные хранятся только на этом Mac.

## Что записывается

- **Активное приложение.** Разрешения не нужны.
- **Заголовок окна:** файл в редакторе, название страницы, чат. Нужен доступ «Универсальный доступ».
- **Сайт в браузере:** Safari, Chrome, Arc, Brave, Edge, Vivaldi, Opera, Яндекс Браузер. Нужен доступ «Автоматизация», macOS спросит его сама. Firefox адреса не отдаёт, для него пишется только заголовок окна.
- **Отсутствие не считается:**
  - простой без мыши и клавиатуры дольше 3 минут (порог меняется в настройках);
  - сон;
  - заблокированный экран.

  Видео и звонки без ввода считаются активностью, это тоже отключается в настройках.

## Что показывает

- **В строке меню:** время за компьютером сегодня.
- **В окне по клику:**
  - периоды День, 7, 30, 60, 90, 180 дней, Год и Всё, со стрелками для перехода к прошлым периодам;
  - за день: почасовой график по приложениям и сетка «каждая минута дня» из 24 × 60 клеток (при наведении видно, что это было);
  - за длинные периоды: часы по дням или неделям и средняя линия;
  - вкладки «Приложения» (клик раскрывает самые частые окна), «Сайты» и «Хронология» (сессии дня с точностью до минуты).
- **Внизу окна:** пауза, настройки, выход.

## Установка

Нужны Xcode Command Line Tools. Если `git` на Mac работает, они уже стоят. Если нет, выполни `xcode-select --install`.

```bash
cd ~/Documents/Learning        # путь к клону репозитория
git pull
cd ActivityTracker
./build.sh --install
```

Скрипт соберёт приложение, положит его в `/Applications/ActivityTracker.app` и запустит. В строке меню появится часик со временем.

При первом запуске:
1. macOS предложит выдать «Универсальный доступ». Открой настройки и включи **ActivityTracker**, иначе заголовки окон писаться не будут.
2. Автозапуск при входе в систему включится сам. Отключается в настройках приложения.
3. Когда откроешь браузер, macOS спросит «ActivityTracker хочет управлять …». Нажми **Разрешить**.

> После каждой пересборки macOS может «забыть» Универсальный доступ: подпись у самодельной сборки каждый раз новая. Если заголовки окон пропали, открой Системные настройки → Конфиденциальность и безопасность → Универсальный доступ, удали ActivityTracker кнопкой «−» и добавь снова (или просто выключи и включи).

### Готовая сборка из GitHub Actions

Каждый push собирает приложение на macOS. Чтобы взять готовую сборку:
1. Открой последний успешный запуск workflow **ActivityTracker** во вкладке Actions.
2. Скачай артефакт `ActivityTracker` и распакуй.
3. Сними карантин скачанного файла и запусти:

```bash
xattr -dr com.apple.quarantine ActivityTracker.app
mv ActivityTracker.app /Applications/ && open /Applications/ActivityTracker.app
```

## Данные

- **Где лежат:** `~/Library/Application Support/ActivityTracker/activity.sqlite`. Кнопка «Показать базу данных в Finder» есть в настройках.
- **Как устроены:** одна таблица `events`. Каждая строка — непрерывный отрезок времени в одном приложении, окне или на одной странице. Поля: `day`, `start_at`, `end_at`, `bundle_id`, `app`, `title`, `url`, `domain`.
- **Как посмотреть вручную:**

```bash
sqlite3 ~/Library/Application\ Support/ActivityTracker/activity.sqlite \
  "SELECT app, ROUND(SUM(end_at - start_at) / 3600.0, 1) AS hours FROM events
   WHERE day >= date('now', '-30 days') GROUP BY app ORDER BY hours DESC LIMIT 10;"
```

## Диагностика

```bash
/Applications/ActivityTracker.app/Contents/MacOS/ActivityTracker --probe
```

Команда печатает, что сборщик видит прямо сейчас: приложение, заголовок, URL, секунды простоя, есть ли доступ. Ещё она проверяет базу данных.
