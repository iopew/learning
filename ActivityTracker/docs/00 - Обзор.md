# ActivityTracker — обзор

> **Цель:** личный трекер активности для Mac. Он записывает, чем я занят, с точностью до минуты, показывает статистику за любой период и в будущем следит за состоянием Mac: батареей, нагрузкой, рекомендациями. Работает локально, данные никуда не уходят.

## Что умеет сейчас

- **Запись каждые 5 секунд:** активное приложение, заголовок окна и адрес вкладки в браузере.
- **Что не считается:** простой (по умолчанию дольше 3 минут без мыши и клавиатуры), сон и заблокированный экран.
- **Строка меню:** время за компьютером сегодня, по клику открывается окошко со статистикой.
- **Большое окно приложения:** значок в Dock (пока окно открыто), открывается из Launchpad или Finder.
- **Периоды:** День, 7, 30, 60, 90, 180 дней, Год и Всё, со стрелками на прошлые периоды.
- **Отчёты:**
  - почасовой график по приложениям;
  - сетка «каждая минута дня»;
  - графики по дням и неделям;
  - приложения (с самыми частыми окнами), сайты, хронология сессий.
- **Настройки:**
  - тема: как в системе, светлая или тёмная;
  - порог простоя;
  - запись заголовков и сайтов;
  - автозапуск;
  - значок в Dock.
- **Обновление:** само, из GitHub Releases, или кнопкой «Обновить». Разрешения macOS при этом сохраняются.

## Где что лежит

| Что | Где |
|---|---|
| Код приложения | `ActivityTracker/` в репозитории `iopew/learning` |
| Документация (эта папка) | `ActivityTracker/docs/` |
| Установленное приложение | `/Applications/ActivityTracker.app` |
| База данных (вся статистика) | `~/Library/Application Support/ActivityTracker/activity.sqlite` |
| Ключ подписи (только этот Mac) | `~/Library/Application Support/ActivityTracker/Signing/` |
| Скачанные обновления и прошлая версия | `~/Library/Caches/com.iopew.ActivityTracker/Updates/` |
| Журнал обновлений | `~/Library/Logs/ActivityTracker/update.log` |
| Сборки на Mac (CI) | GitHub → Actions → workflow **ActivityTracker** |
| Готовые версии | GitHub → Releases, теги `activity-tracker-build-N` |
