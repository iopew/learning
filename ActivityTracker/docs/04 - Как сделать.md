# Как сделать…

## Установить в первый раз (или после поломки)

**Вариант А: готовая сборка, без инструментов разработчика**
1. GitHub → репозиторий `iopew/learning` → **Releases** → последняя `ActivityTracker — сборка N` → скачать `ActivityTracker.zip`.
2. Распаковать и выполнить в Терминале из папки «Загрузки»:
   ```bash
   xattr -dr com.apple.quarantine ActivityTracker.app
   rm -rf /Applications/ActivityTracker.app
   mv ActivityTracker.app /Applications/
   open /Applications/ActivityTracker.app
   ```
3. При первом запуске приложение один раз перезапустится само: оно переподписывается постоянным локальным ключом. Это нормально.
4. Выдать доступ: Системные настройки → Конфиденциальность и безопасность → **Универсальный доступ** → ActivityTracker. Если в списке висит старая запись ActivityTracker, удалить её кнопкой «−».

**Вариант Б: собрать из исходников** (нужны Xcode Command Line Tools: `xcode-select --install`)
```bash
cd <папка репозитория>/ActivityTracker
./build.sh --install
```

## Обновить

Ничего делать не нужно. Раз в 30 минут приложение проверяет GitHub и ставит новую сборку само. Вручную: окно → Настройки → «Проверить сейчас», или кнопка «Обновить» в синей полосе.

## Выпустить новую версию

Сделать push изменений в `ActivityTracker/` в `main` или в ветку `claude/...`. Дальше CI сам:
1. прогонит тесты и соберёт приложение;
2. проверит подпись и сквозное обновление;
3. опубликует релиз `activity-tracker-build-N`.

Проследить: GitHub → **Actions** → ActivityTracker → последний запуск.

## Посмотреть, что происходит

| Что | Как |
|---|---|
| Что видят сборщики прямо сейчас | `/Applications/ActivityTracker.app/Contents/MacOS/ActivityTracker --probe` |
| Журнал обновлений | `open ~/Library/Logs/ActivityTracker/update.log` или Настройки → «Журнал обновлений» |
| Сырые данные | `sqlite3 ~/Library/Application\ Support/ActivityTracker/activity.sqlite` |
| Какая версия стоит | Настройки → «Обновления» → «Версия 1.1 (сборка N)» |
| Чем подписано приложение | `codesign -d -r- /Applications/ActivityTracker.app` |

Полезные запросы к базе:
```sql
-- топ приложений за 30 дней, в часах
SELECT app, ROUND(SUM(end_at - start_at) / 3600.0, 1) AS hours FROM events
WHERE day >= date('now', '-30 days') GROUP BY app ORDER BY hours DESC LIMIT 10;

-- сколько YouTube по дням
SELECT day, ROUND(SUM(end_at - start_at) / 60.0) AS minutes FROM events
WHERE domain = 'youtube.com' GROUP BY day ORDER BY day DESC LIMIT 14;
```

## Поставить приложение на iPhone

Одной кнопкой на Mac — Xcode открывать не нужно.

Один раз подготовить:
1. Установи Xcode из App Store (бесплатно) и запусти его один раз — согласись с лицензией и дай доставить компоненты.
2. Xcode → Settings → Accounts → «+» → Apple ID — войди своим Apple ID.
3. На iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить (iPhone перезагрузится).

Каждый раз (и раз в 7 дней, когда истекает бесплатная подпись):
1. Подключи iPhone кабелем, разблокируй, при вопросе нажми «Доверять».
2. На Mac: ActivityTracker → Настройки → **iPhone** → «Установить на iPhone» (потом — «Обновить приложение на iPhone»).
3. Приложение само скачивает код с GitHub (в свою папку `~/Library/Application Support/ActivityTracker/iphone-src`), собирает его Xcode, подписывает твоим Apple ID, ставит на iPhone, **само связывает iPhone с Mac** и открывает приложение. Первый раз — до 10 минут.
4. Только в первый раз: iPhone скажет «Ненадёжный разработчик» — Настройки → Основные → VPN и управление устройством → твой Apple ID → «Доверять».
5. macOS может спросить пароль связки ключей для codesign — «Всегда разрешать».

Если что-то не так — кнопка «Журнал» рядом открывает подробный лог (`~/Library/Logs/ActivityTracker/iphone-install.log`).

Вручную через Xcode (если кнопка не справилась): `git clone -b claude/trusting-galileo-9vcql7 https://github.com/iopew/learning.git ~/Developer/activitytracker-src` (не в папку Obsidian), открыть `ActivityTracker/Phone/ActivityPhone.xcodeproj`, Signing & Capabilities → Team, выбрать iPhone, ▶.

## Связать iPhone с Mac

0. Если ставил кнопкой на Mac — связь уже настроена, этот раздел можно пропустить.
1. На Mac: ActivityTracker → Настройки → **iPhone** → «Связать с iPhone» — появится QR-код.
2. На iPhone: вкладка «Настройки» → «Связать с Mac» → навести камеру на код. iPhone спросит про доступ к локальной сети — разреши.
3. Статистика обновляется, когда открываешь приложение (или потяни список вниз). Mac и iPhone должны быть в одной сети: общий Wi-Fi или Mac на режиме модема iPhone.
4. Вне общей сети — Tailscale: поставь его на Mac и iPhone (один аккаунт). Если он был включён при связке, адрес Mac уже известен; иначе впиши адрес Mac из Tailscale (`100.x.y.z`) в «Адрес Mac вручную».
5. Если сеть не даёт устройствам видеть друг друга (бывает на работе): на Mac «Отправить снимок через AirDrop» → на iPhone открыть файл в ActivityTracker.
6. «Отвязать» на Mac делает старый QR-код бесполезным; чтобы связать заново, покажи новый код.

## Удалить что-то из истории

- **Сайт или приложение целиком:** в списке «Сайты» или «Приложения» наведи на строку и нажми корзину справа (или правый клик → «Удалить все данные…»).
- **Последние 15 минут, час, сегодня или всё:** меню **«Забыть»** рядом с «Пауза» в окне и в окошке строки меню, или Настройки → «Данные».
- Удаление необратимо, данные затираются в файле базы.

## Сменить язык или тему

Настройки → «Язык» (Как в системе / Русский / English) и «Оформление» (Как в системе / Светлая / Тёмная). Меняется сразу, без перезапуска.

## Команды в Терминале

Настройки → «Команда в Терминале» → «Установить команду activitytracker». Если `~/.local/bin` не в PATH, выполни один раз то, что покажут настройки. Дальше:
```bash
activitytracker today                    # день словами
activitytracker report 7d                # итог недели (--json для программ)
activitytracker export 30d --full --out ~/Desktop/a.csv
activitytracker sql "SELECT day, app, ROUND(seconds/3600.0,1) FROM daily_apps ORDER BY day DESC LIMIT 20"
activitytracker pause 30m                # или 2h, tomorrow; resume — продолжить
```
Пример на Go (драйвер `modernc.org/sqlite`, путь даёт `activitytracker db`): `SELECT app, SUM(seconds) FROM daily_apps WHERE day >= date('now','-7 day') GROUP BY app`.

## Скачать базу, почистить, открыть старую копию

Настройки → «База данных»:
- **«Скачать базу…»** — копия всей истории в выбранную папку (`ActivityTracker-ГГГГ-ММ-ДД.sqlite`);
- **«Открыть сохранённую…»** — просмотр копии в отдельном окне, текущая база не меняется. Так же работает перетаскивание файла на значок приложения;
- **«Удалить старые данные»** — старше 30, 90, 180 дней или года, затем база сжимается;
- **«Сжать базу»** — после больших удалений файл становится меньше.

## Посмотреть трафик и пинг

Окно → «Сеть»:
- период выбирается так же, как в «Активности»;
- у каждой сети свой блок: трафик, скорость, пинг, обрывы, сигнал;
- значок карандаша переименовывает сеть.

Если вместо имени Wi-Fi видно «Wi-Fi (192.168.1.1)»: Системные настройки → Конфиденциальность и безопасность → Службы геолокации → включить ActivityTracker.

## Сменить начало дня

Окно → «Ритм» (или Настройки) → «Новый день начинается в». По умолчанию 04:00: работа до 03:59 идёт во вчерашний день. После смены нажать «Перезапустить»: приложение перезапустится и один раз пересчитает всю историю.

## Настроить уведомления

Настройки → «Уведомления»: итог дня и время (18:00–23:00), напоминания о перерыве. Если уведомления не приходят: Системные настройки → Уведомления → ActivityTracker → разрешить.

## Посмотреть тренд приложения или сайта

Окно → «Сравнение» → нажать на строку. Или правый клик по приложению или сайту в списках → «Тренд за 90 дней».

## Если не пишутся заголовки окон

После переустановки вручную macOS могла запомнить старую подпись.
1. Системные настройки → Конфиденциальность и безопасность → Универсальный доступ.
2. Удалить ActivityTracker кнопкой «−», затем добавить заново «+» → Программы → ActivityTracker, или просто перезапустить приложение: оно само спросит.

## Если не пишутся сайты

Системные настройки → Конфиденциальность и безопасность → **Автоматизация** → ActivityTracker → включить нужные браузеры.

## Вернуть прошлую версию

Прошлая версия лежит в `~/Library/Caches/com.iopew.ActivityTracker/Updates/previous.app`:
```bash
pkill -x ActivityTracker
rm -rf /Applications/ActivityTracker.app
ditto ~/Library/Caches/com.iopew.ActivityTracker/Updates/previous.app /Applications/ActivityTracker.app
open /Applications/ActivityTracker.app
```
Чтобы она не обновилась обратно, отключи «Устанавливать автоматически» в настройках.

## Удалить полностью

```bash
pkill -x ActivityTracker
rm -rf /Applications/ActivityTracker.app
rm -rf ~/Library/Application\ Support/ActivityTracker      # данные и ключ подписи
rm -rf ~/Library/Caches/com.iopew.ActivityTracker ~/Library/Logs/ActivityTracker
defaults delete com.iopew.ActivityTracker
```
И убрать ActivityTracker из «Универсального доступа», «Автоматизации» и «Объектов входа» в Системных настройках.
